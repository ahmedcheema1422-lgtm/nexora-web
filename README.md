# Nexora Website

## Run locally
1. Run `npm install`.
2. Run `npm run dev`.
3. Open the local Next.js URL shown in the terminal.

## Production
- `npm run build` creates an optimized Next.js build.
- `npm start` serves the production build.

The chatbot uses built-in answers and does not need an API key or internet connection.
